# Crit 8 reflection

## What was the breakthrough that moved the work forward?

This week I had a much bigger idea for the project than I needed for the first crit: different guinea pig personalities, multiple areas of the sanctuary, and cooperative building. The moment that moved things forward was when I stopped building toward the whole design at once and focused on proving the core idea worked.

That became clearest when choosing the second persistent interaction. I considered letting visitors leave named notes — simple to implement, but it started to feel like a guestbook or activity feed, which goes against my README's idea of leaving traces without turning the sanctuary into a social platform. The agent flagged that tension when presenting the options; I agreed and chose planting a flower instead, a small interaction that changes the shared environment itself and persists for future visitors.

Before that, I was treating the README as an explanation of the project. After this, I started treating it as something that should constrain what I build.

## What did this change about who I want to be as a software developer?

Working with an agent changed how I think about my role. An agent can produce a working implementation quickly, which makes it tempting to judge progress by how much has been produced. But I still need to understand why each feature exists, whether it fits the project, and be able to explain the decisions behind it.

Writing CLAUDE.md made this obvious. Instead of just telling the agent what to build next, I was defining rules future implementations should follow — closer to designing the system's boundaries than requesting code.

Going forward, I want to give an agent constraints before asking it to implement something, and treat rejecting or simplifying its suggestions as part of development. I'd rather have a smaller system I can account for than a larger one that works but no longer reflects what I meant to build.
